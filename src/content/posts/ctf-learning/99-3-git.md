## 六、git 速查（源码泄露题用）

| 命令 | 作用 |
|---|---|
| `git log --all --oneline` | 看所有分支的提交（**`--all` 不能省**） |
| `git show <commit>` | 看某次提交改了什么 |
| `git show <commit>:<文件>` | **读某个版本里的某个文件**（冒号后跟文件名） |
| `git branch -a -v` | 看所有分支（只能看到还存在的） |
| `git reflog --all` | **行动流水账** → 能发现**已被删除的分支/提交** |
| `git fsck --lost-found` | 找游离（dangling）对象 |
| `git ls-tree -r <commit>` | 列出某次提交里的所有文件 |
| `git cat-file --batch-all-objects --batch-check` | 列出仓库里所有对象 |

> **核心认知**：**git 里"删除"只是删掉引用，旧对象还在 `.git/objects/` 里。**
> 报 `dubious ownership` 时，**只信任该仓库的绝对路径**：
> `git config --global --add safe.directory "<仓库绝对路径>"`
> ⚠️ 别用 `"*"`（等于对所有仓库关闭检查，而你正在分析来源不可信的仓库）。
