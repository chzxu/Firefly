## 七、编码速查

| 编码 | 长什么样 | 本套笔记中的位置 |
|---|---|---|
| URL 编码 | `%E7%BB%87%E4%BA%91%E9%98%81` | 03 第二关 |
| Base64 | `bW9lY3Rme0Mw`（结尾常有 `=`） | 03 各关碎片 / 04 |
| UTF-16BE | 字节形如 `00 66 00 6c` | 04 的 `.DS_Store` |
| 二进制（字符替换） | `eiieeiie`（e=0, i=1） | 05 |
| JSON 转义 | `\u5929\u8d4b` | 01 回显 |

### 二进制 ⇄ 字符（最常用的一段）

```python
# 二进制串 → 文本
bits = "".join("1" if c == "i" else "0" for c in s)          # e=0, i=1
b = bits[:len(bits)//8*8]
text = "".join(chr(int(b[i:i+8], 2)) for i in range(0, len(b), 8))

# 文本 → 二进制
bits = "".join(f"{ord(c):08b}" for c in "flag{")
```

### 一键排查"这是哪种编码"

| 特征 | 判断 |
|---|---|
| 只有两种字符 | 二进制 / 摩斯 / 培根密码 |
| 结尾有 `=`，字符集 `A-Za-z0-9+/` | Base64 |
| `%` + 两个十六进制 | URL 编码 |
| 全是十六进制字符 | Hex |
| 开头 `PK` | ZIP 压缩包 |
| 中间大量 `\x00` | UTF-16 |
| 32 位十六进制、以 `0e` 开头且后面全是数字 | **魔法哈希**（PHP `==` 会把它当数字 0） |

### 魔法哈希速查（PHP 类型戏法）

**用途**：题目要求「a ≠ b，但 `md5(a) == md5(b)`」时使用。
原理：PHP 松散比较 `==` 会把 `0e+纯数字` 当成科学计数法 = **0**，于是 `0 == 0` 成立。

任选两个不同的填进去即可：`?a=QNKCDZO&b=240610708`

| `s878926199a` | `0e545993274517709034328855841020` |
| `s155964671a` | `0e342768416822451524974117254469` |
| `s214587387a` | `0e848240448830537924465865611904` |
| `s1091221200a` | `0e940624217856561557816327384675` |
| `s1885207154a` | `0e509367213418206700842008763514` |
| `s1836677006a` | `0e481036490867661113260034900752` |
| `s1184209335a` | `0e072485820392773389523109082030` |
| `s1502113478a` | `0e861580163291561247404381396064` |
| `s532378020a` | `0e220463095855511507588041205815` |
| `0e215962017` | `0e291242476940776845150308577824` |

| 备选招 | 写法 | 版本限制 |
|---|---|---|
| **数组绕过** | `?a[]=1&b[]=2` | 只在 **PHP 7** 有效（`md5(数组)` 返回 NULL）；**PHP 8 直接致命错误** |
| **真实 MD5 碰撞** | 两个不同二进制串、md5 完全相同 | 用于 `===` 严格比较的场景，需 URL 编码 |

**一句话**：`==` 和 `===` 的区别不是风格问题，是**安全问题**。
